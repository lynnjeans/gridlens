本包把已有 Seen Ventures AI Research Assistant 两周 PRD 转成可执行的开发规格和 36 个 AI 开发任务。应用现已完成 T01–T14、T16、T33，其余20项待实施；实际证据见 progress.md。

## 现在如何开始

当前是接手已有项目：先读 `HANDOFF.md` 和应用根 `AGENTS.md`。T01–T14、T16、T33 已完成，**从 T15 确定性分块继续**，不要重建项目。可直接使用 HANDOFF 第 7 节提示词。

应用位于父工作区的独立 `gridlens/` 目录；当前实现已提交并推送到 GitHub `master`，可以通过仓库 clone，也可使用源码交接包。下一步按依赖实现 PDF → 快照/审核 → 入库 → 引用问答 → 缺口/导出 → 真实评估；OAuth T34 可从已完成凭证基础继续。

## 关键约定

- 本地 Python + Streamlit + SQLite + Chroma；Tavily 搜索独立配置。生成使用 ChatGPT 官方 OAuth 订阅授权，embedding 使用本地 BGE，不需平台 API key。
- T33–T36 为新增授权任务，必须按依赖先于 T21；生成模型来自选中账户目录。
- 本地 embedding 初次显式下载，固定 revision，384 维、350/50 分块；缺缓存/授权/额度需分别处理。
- 单人、本地、NZ 优先；文本型 HTML/PDF。电力仿真不在本包范围内。
- 自动化的是代码实现、测试和任务推进；真实研究来源仍需人工批准，研究语义质量仍需人工评分。
- Fixture 测试、真实服务联调和人工验收分别记录，不互相冒充。
- docs 中的路径、方法和命令属于待实现应用约定；本地应用已安装基础依赖并通过离线测试；代码已发布到指定 GitHub origin，但尚未调用真实模型。

## 文档一致性

任务详情以 `tasks.json` 为机器主清单，`02_AI_TASKS.md` 为阅读版；修改时同步。实际执行证据记入应用 `docs/progress.md`；当前摘要见 `docs/HANDOFF.md`。

开发规格补充了 Candidate 版本状态、幂等提交、不可变快照与 provider 默认选择，并保留 PRD 的产品目标及验收阈值。遇到冲突，以用户的新指示为先，其次保持产品要求，修正实现契约并记录变化，不能静默删减功能。

本包只包含文档。原 PRD 中引用的项目 brief 本地链接在其他电脑上可能不可用，可依据文件标题回到项目资料查找；无需修改原文档才能使用开发规格和任务卡。
